# Eita nóis 2.0

Estúdio de conteúdo no navegador: post em vídeo (briefing, revisão e entrega), estáticos, motion graphics com prévias ao vivo, oportunidades, Creator Room (Avaliador, Respiro e Ronda) e marca.

O app inteiro está no `index.html`. Na pasta `arquivos-zai` ficam as versões anteriores usadas de base, o guia de subida e os prints de teste.
